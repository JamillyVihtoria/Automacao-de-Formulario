# 📝 Automação de Formulário - DemoQA
Este projeto demonstra a automação do preenchimento de formulários utilizando Python + Selenium. O script acessa o site DemoQA Practice Form, insere dados de exemplo nos campos, seleciona gênero, data de nascimento, hobbies e envia o formulário automaticamente.

# 🚀 O que o código faz
- Abre o navegador Chrome maximizado.
- Acessa o formulário de prática da DemoQA.
- Preenche os campos de nome, sobrenome e e-mail.
- Seleciona o gênero.
- Insere número de telefone.
- Escolhe uma data de nascimento específica (26/07/2003 no exemplo).
- Marca múltiplos hobbies (Esportes, Leitura e Música).
- Envia o formulário automaticamente.

# 🛠️ Ferramentas utilizadas
- Python
- Selenium WebDriver
- WebDriverWait para sincronização de elementos
- ChromeDriver

# ▶️ Como executar
- Clone o Repositório
- Instale as dependências: pip install selenium
- Baixe e configure o ChromeDriver compatível com a versão do seu navegador:
  https://developer.chrome.com/docs/chromedriver/downloads?hl=pt-br
- Execute o script
